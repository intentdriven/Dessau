# Bob gets answers in the exact JSON shape he asks for

## Press Release

> Bob asks for an answer in a shape he defines and gets exactly that shape. He sends a JSON schema with his request, the way OpenAI clients already do, and Dessau makes the model answer only with JSON that fits it, so his script can read the answer without checking and retrying. A schema Dessau cannot apply is refused with the reason before the model starts, rather than producing an answer that does not fit.
