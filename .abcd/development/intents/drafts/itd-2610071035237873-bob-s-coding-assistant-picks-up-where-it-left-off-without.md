# Bob's assistant picks up where it left off after Dessau unloads the model

## Press Release

> Bob's coding assistant picks up where it left off without waiting for Dessau to reread the whole conversation. When Dessau unloads a model to make room, or restarts, it keeps the work it had already done on Bob's long prompts on this Mac's disk, in Alice's own account, and uses it again when the same conversation returns, so his next answer starts in a second or two rather than after the model has reread tens of thousands of tokens. Nothing from one model's saved work is ever used for another model or another version of it, and Alice can see how much disk it uses and clear it.
