# Alice fits a longer conversation, or one more model, into the same memory

## Press Release

> Alice fits a longer conversation, or one more model, into the same memory. In a model's settings she turns on compact conversation memory, and Dessau keeps that model's working memory for each conversation at about half its usual size, so the window it serves can grow or another model can stay loaded beside it. Alice chooses this per model, because a model kept compact answers one request at a time and may answer very long prompts slightly less exactly; the setting tells her both before she turns it on, and nothing turns it on by itself.
