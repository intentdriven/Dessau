# Principles

The opinionated conventions the OPINIONS rule domain points at. Each file
carries one rule as `abcd rules OPINIONS` renders it, the reasons this
repository's own record gives for it, and the places in this repository where
it already bites.

These files explain rules; they do not create them. The rules themselves live
in the abcd rule loader, and the repository's own working conventions live in
AGENTS.md.

## The rules

- [Prefer SOTA, adversary-filtered](prefer-sota.md) — a credible
  state-of-the-art answer is the presumptive pick, challenged for fit before it
  is adopted.
- [One canonical primitive](one-canonical-primitive.md) — find the canonical
  home and extend it; never add a third copy.
- [Evaluator outside the loop](evaluator-outside-the-loop.md) — the reviewer is
  independent of whoever proposed the option.
- [Verifier selects, gates decide](verifier-selects-gates-decide.md) — a
  verdict is a proposal; the adoption is the gate.
- [Loud staging](loud-staging.md) — a stage that no-ops or degrades says so;
  no false greens.
- [Script-first MVP](script-first-mvp.md) — earn each tool rung; the smallest
  documented protocol is the MVP.
- [Memory graduates to the record](memory-graduates-to-record.md) — a lesson
  any agent should receive belongs in the committed record.
- [Pre-existing is not a defence](pre-existing-is-not-a-defence.md) — fix it,
  or defer it out loud on the record.
- [The user's directory is theirs](the-users-directory-is-theirs.md) — scratch
  goes in the tiers set aside for it.

## Reading one

`abcd rules OPINIONS` renders the active rule set. Each rule ends with a
pointer to its file here.
