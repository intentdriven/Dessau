Connect

Dessau speaks the OpenAI API, so anything that talks to ChatGPT can talk to this Mac. Point it here.

Base URL

Base URL

http://alices-mac.local:8080/v1

Also answering at http://192.0.2.24:8080/v1, and on this Mac at http://127.0.0.1:8080/v1.

API key

Set. Every request on port 8080 must send it.

Try it

curl http://alices-mac.local:8080/v1/chat/completions \
  -H "Authorization: Bearer $DESSAU_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "mlx-community/Qwen3-8B-4bit",
       "messages": [{"role": "user", "content": "Hello"}]}'
import os
from openai import OpenAI

client = OpenAI(base_url="http://alices-mac.local:8080/v1",
                api_key=os.environ["DESSAU_KEY"])
reply = client.chat.completions.create(
    model="mlx-community/gemma-3-12b-it-4bit",
    messages=[{"role": "user", "content": "Hello"}])
print(reply.choices[0].message.content)

Clients

Chat apps paired with this server. A paired app proves itself with a key of its own and never sends the API key. Anything that reaches this server can pair, so revoke what you do not recognise.

This server’s fingerprint

SHA256 3F9A 7C21 B04E 66D8 91AF 2C5B 0E73 D4A9

Compare it with the fingerprint the chat app shows. If the two differ, the app is talking to something else.

Posture

What this server exposes and to whom, as Dessau sees it now, and where its view stops. Nothing here is a warning, and nothing here changes a setting.

Who can reach the API

Anyone on your network, on port 8080.

Bound to every network interface. Dessau cannot see your router or firewall.

Whether a key is needed

Every request on port 8080 must send the API key.

A blank key would let anyone on your network use the server.

Who can pair a chat app

Anything that reaches port 8081.

Pairing is first come; 4 apps are paired now.

How it is found

Announced over Bonjour as alices-mac.local.

Announcing is how a server is found, never what it allows.

Who can open this panel

Only someone at this Mac.

Bob and Carol reach the API, never the panel.

What is recorded

Counts and timings, on this Mac.

Anyone who can open this panel can read them.

Whether conversations are kept

No model keeps a transcript.

Debug logging is off for every model.

What leaves this Mac

Model names, to HuggingFace, once a day.

For the update check. The Discord bridge is off.
