Paired chat clients

Dessau Chat pairs once and then uses a key of its own on port 8081. It never needs the API key.

Try it

curl http://alices-mac.local:8080/v1/chat/completions \
  -H "Authorization: Bearer $DESSAU_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "mlx-community/Qwen3-8B-4bit",
       "messages": [{"role": "user", "content": "Hello"}]}'
import os
from openai import OpenAI

client = OpenAI(base_url="http://alices-mac.local:8080/v1",
                api_key=os.environ["DESSAU_KEY"])
reply = client.chat.completions.create(
    model="mlx-community/gemma-3-12b-it-4bit",
    messages=[{"role": "user", "content": "Hello"}])
print(reply.choices[0].message.content)

Asking for a model that is not loaded loads it first; the answer then takes a few seconds longer.
