      The API key

      Set, and required on port 8080

      sk-dessau-••••••••3f9a

      Paired chat clients use keys of their own on port 8081 and never send this one.

      Try it

      curl http://alices-mac.local:8080/v1/chat/completions \
  -H "Authorization: Bearer $DESSAU_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "mlx-community/Qwen3-8B-4bit",
       "messages": [{"role": "user", "content": "Hello"}]}'
      import os
from openai import OpenAI

client = OpenAI(base_url="http://alices-mac.local:8080/v1",
                api_key=os.environ["DESSAU_KEY"])
r = client.chat.completions.create(
    model="mlx-community/gemma-3-12b-it-4bit",
    messages=[{"role": "user", "content": "Hello"}])
print(r.choices[0].message.content)
