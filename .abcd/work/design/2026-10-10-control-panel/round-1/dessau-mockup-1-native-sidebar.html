Example 

curl http://alices-mac.local:8080/v1/chat/completions \
  -H "Authorization: Bearer $DESSAU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "mlx-community/Qwen3-8B-4bit",
       "messages": [{"role": "user", "content": "Hello"}]}'
from openai import OpenAI

client = OpenAI(base_url="http://alices-mac.local:8080/v1",
                api_key=os.environ["DESSAU_API_KEY"])
reply = client.chat.completions.create(
    model="mlx-community/Qwen3-8B-4bit",
    messages=[{"role": "user", "content": "Hello"}])
print(reply.choices[0].message.content)

The model field names any model on My Models. Dessau loads it if it is not loaded, unloading an idle one if it needs the room.

How requests are handled

Sampling defaults serve every request that leaves the parameter out; a request that sets its own value always wins. A change reaches a model the next time it loads.
