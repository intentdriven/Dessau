Connecting an app, step by step

  1. In the app's settings, find where it asks for an OpenAI base URL or custom endpoint, and paste the address.

  2. Paste the key where it asks for an API key.

  3. For the model, type one of yours, such as mlx-community/Qwen3-8B-4bit.

For developers

curl http://alices-mac.local:8080/v1/chat/completions \
  -H "Authorization: Bearer $DESSAU_API_KEY" \
  -H "Content-Type: application/json" \
