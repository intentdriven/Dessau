OpenAI-compatible

Point any OpenAI client here.

Anything that talks to ChatGPT can talk to this Mac: set the base URL and the API key.

Base URL

http://alices-mac.local:8080/v1

Also answering on http://192.0.2.24:8080/v1 and, on this Mac, http://127.0.0.1:8080/v1.

API key

Required

Every request on port 8080 must send the key as a Bearer token. Paired chat clients use a key of their own on port 8081 instead.

sk-dessau-••••••••••••3f9a

Example

curl http://alices-mac.local:8080/v1/chat/completions \
  -H "Authorization: Bearer $DESSAU_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-community/Qwen3-8B-4bit",
    "messages": [{"role": "user", "content": "Hello from Bob"}]
  }'
import os
from openai import OpenAI

client = OpenAI(
    base_url="http://alices-mac.local:8080/v1",
    api_key=os.environ["DESSAU_KEY"],
)
reply = client.chat.completions.create(
    model="mlx-community/gemma-3-12b-it-4bit",
    messages=[{"role": "user", "content": "Summarise this in a line."}],
)
print(reply.choices[0].message.content)
